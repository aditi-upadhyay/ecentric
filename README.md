# ecentric

Creating an interactive 3D scene featuring a Fresnel effect applied to a PBR (Physically Based Rendering) material on a 3D object.

**Live demo:** [https://ecentric-labs.netlify.app/](https://ecentric-labs.netlify.app/)

## Setup

1. Clone the repository and enter the project directory:

   ```bash
   git clone <repository-url>
   cd ecentric
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

4. Open [http://localhost:4200](http://localhost:4200) in your browser.

## Commands

| Command | Description |
|---------|-------------|
| `npm start` | Start the dev server |
| `npm run build` | Production build |
| `npm run watch` | Build in watch mode |
| `npm test` | Run unit tests |
